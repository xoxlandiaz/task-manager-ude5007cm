# Task & Project Management System (UDE5007CM)

Full-stack веб-приложение для управления проектами и задачами: Node.js, Express, PostgreSQL, Bootstrap.

- Установка: [docs/install-guide.md](docs/install-guide.md)
- Деплой: [DEPLOY.md](DEPLOY.md)

| Папка | Зона | Тред |
|---|---|---|
| `db/` | схема, миграции, сиды, ER-диаграмма | «База данных» |
| `server/` | Express REST API | «Бэкенд» |
| `public/` | HTML/CSS/JS на Bootstrap | «Фронтенд и дизайн» |
| `.github/`, `render.yaml`, `Dockerfile`, `docker-compose.yml`, `nginx/`, `.env.example`, `package.json` | CI, деплой | «DevOps и деплой» |
| `docs/` | отчёт, API-документация, гайды | общая |
| `tests/` | тесты API | «Бэкенд» (+ CI от DevOps) |
